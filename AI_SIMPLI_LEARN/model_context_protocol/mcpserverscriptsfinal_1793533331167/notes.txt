After you sign in you land on the ngrok dashboard (dashboard.ngrok.com).

Click the copy icon next to the token. Keep it private, like a password. You will paste it into
the terminal in the next step.

Step 8: Connect Claude
You can use a free Claude account. On the Free plan you can add one custom connector, so if
you already added one, remove it first. Menu names change from time to time; the paths below
are the current ones from Claude's help pages.
1. Open claude.ai in your browser (or the Claude desktop app) and sign in.
MarketIntel MCP Demo | Page 4
MarketIntel MCP Demo | Page 5
2. Go to Customize > Connectors. Direct link: claude.ai/customize/connectors. In some
older versions this is called Settings > Connectors.
3. Click Add custom connector.
4. Fill in the dialog:
• Name: MarketIntel
• MCP server URL: your ngrok address ending in /mcp
• Authentication: choose No sign-in (this demo server has no login). If your dialog shows
OAuth Client ID and Secret under Advanced settings, leave them empty.
• Transport: leave the default. A URL ending in /mcp is correct.
5. Click Add. Watch your server terminal: you should see [HTTP] lines and usually [INIT]
and [LIST] as Claude connects and reads the tool list.
6. Open a new chat, click the + button, choose Connectors, and switch MarketIntel on for
this conversation.
Team or Enterprise plan: an Owner must first add the connector in Organization settings >
Connectors. You then go to Customize > Connectors, find MarketIntel (it has a Custom label)
and click Connect.
