Multi-agent market research & launch planner--->think of any domain any product launch as your projecthow system is built and how work flows in n8n and in CrewAIHead plannerResearch AgentAnalyst AgentStrategy Agentthink for production ready AI agent system(read/study owl and tower system and gain good knowledge for it)the problem: planning a product launch takes daysbefore launching a product, team must answer: who are we competing with?What do they charge?who should we sell to, and we reach them?Today people search articles, compare completitors and wrtite the launch plan (called GTM - Go To Market plan) by handDays/Months of manual workSlow:  by the time plan is ready, the market may have changedMistakes happen: people miss important points and forget where facts came fromDifferent every time: two people, or two rounds, produce different resultsthe goal of project: brief in, launch plan out in 15min (recommended)project brief:  a short form of project4 AI Agents: find facts->compare->planLaunch plan: google doc+ pdf, with sourceshow we know it worksquestions answered (ge 90), good sources(ge 80), speed(less 15min), plan quality(ge 4 / 5), consistency(ge 80), cost (le cap)how someone arrive at the solutions needs to be clearly evaludatedmust be a way to gauge that the result is valid (manually and via references) and not helluciated oneMeet the team: 4 agents, 1 job - 4 pillersHead planner - the manager - like a project manager, break the brief into ques, hands out tyhe work, then write the final reportResearch Agent - the finder - like a librarian: searches the web, reads pages, and saves every fact with its linkAnalyst Agent - the thinker - like a detective: turns a pile of fact into side-by-side comparisions and a list of strengths and weaknessesStrategy Agent - the planner - like a marketting lead: uses those findings to write the launch planARCHITECTURE AT A GLANCE┌───────────────┐    ┌──────────────────────────────────────────────┐    ┌──────────────┐│ Project brief │───▶│          HEAD PLANNER (the manager)          │───▶│  Google Doc  ││ user fills a  │    │ makes the plan • hands out work •            │    │    + PDF     ││ form or chat  │    │ checks quality • writes the final doc        │    └──────────────┘└───────────────┘    └──────────────────────────────────────────────┘                          │ hands out work                 ▲ sends draft back                          ▼                                │                ┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐                │  RESEARCH AGENT  │──▶│  ANALYST AGENT   │──▶│  STRATEGY AGENT  │                │ → facts w/ links │   │ → comparisons    │   │ → launch plan    │                │                  │   │                  │   │   draft          │                └──────────────────┘   └──────────────────┘   └──────────────────┘                          │                          ▼SHARED TOOLS    ┌ ─ ─ ─ ─ ─ ─ ─ ─ ┐ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ┐ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ┐ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ┐                   SerpAPI           MCP server          LLM (AI model)      Google Docs API                │ Google search  │ │ opens & reads  │ │ the brain: reads│ │ creates the    │                  for agents         web pages          & writes            document                └ ─ ─ ─ ─ ─ ─ ─ ─ ┘ └ ─ ─ ─ ─ ─ ─ ─ ─ ┘ └ ─ ─ ─ ─ ─ ─ ─ ─ ┘ └ ─ ─ ─ ─ ─ ─ ─ ─ ┘TRACKING        Every step records: how long it took • how much AI it used and                what it cost • any retries after errorswhy not autogen over crewai? -
